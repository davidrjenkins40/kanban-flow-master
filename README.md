# Kanban Flow Master

A 2D hi-bit pixel art arcade puzzle-management game built to teach core Kanban principles—managing flow, limiting Work in Progress (WIP), spotting bottlenecks, and preventing team overburdening—in a fast-paced 5-day workweek campaign.

Built as a **100% self-contained single HTML file** using HTML5 Canvas 2D and synthesized Web Audio, with zero external assets or dependencies.

## How to Play

1. **Pull work left to right:** Drag work cards from **New** > **Approved** > **Analysis** > **Development** > **Testing** > **Done**.
2. **Respect the timers:** Cards must finish processing in an active column before they can move forward.
3. **Watch your WIP:** Overloading a column slows down processing and stresses the team.
4. **Don't let cards boil over:** Completed cards left sitting too long turn red, vibrate, and drain your Customer Value score.
5. **Survive the week:** Progress from Monday through Friday, culminating in a boss battle against a major 3rd-party supplier outage (**Apex Vendor Corp**).

## Features

* **5-Day Escalating Campaign:** Monday through Friday, introducing blocker cards, sick leave slowdowns, senior management pet projects, cybersecurity emergencies, and a Friday supplier boss fight.
* **Diverse Animated Avatars:** Four rotating workforce characters (**Priya**, **Marcus**, **Kenji**, and **Clara**) whose expressions and body language react in real time to your board's flow health.
* **Modern Hi-Bit Pixel Art:** Procedurally rendered 16-bit sprites, folded index cards, confetti bursts, and a clean studio Kanban board.
* **Synthesized Chiptune Audio & Haptics:** Built-in Web Audio soundtrack and retro sound effects, plus mobile haptic feedback.
* **Attract Mode:** Plays itself automatically on load and hands control over the moment you click or tap.

## Running Locally

Just download `index.html` and open it in any modern web browser—no build step, server, or internet connection required.
